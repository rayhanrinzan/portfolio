# Your drawings (optional, highest-impact upgrade)

Claude Code can draw decent SVG doodles, but hand-drawn art made by you will
always look more alive and more like *your* site.

If you want to draw the room (Procreate, Fresco, Excalidraw, even paper + phone):

- Draw each object on its own layer: wall/window, desk, laptop, mug, plant,
  bookshelf, corkboard, phone/envelope, foreground.
- Export each layer as a transparent PNG at 2x, or SVG if your app supports it.
- Keep lines thin and slightly wobbly; flat fills from the palette in CLAUDE.md.
- Drop the files here. Claude Code will vectorize, layer, and animate them.
